# Wolt Blocker

Chrome extension that adds a one-click way to hide restaurants and shops on `wolt.com`.

## What it does

- Adds a `Hide` button on Wolt restaurant and shop cards.
- Persists blocked venues in Chrome storage.
- Hides blocked venues everywhere they appear in Wolt listings.
- Lets you unblock venues from the popup or the options page.

## Install locally

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `d:\git\wolt-blocker`.

## How to use

- On Wolt listing pages, hover a restaurant or shop card and click `Hide`.
- On an individual venue page, use the inline `Hide this venue` button or the extension popup.
- Open the extension options page to search, review, and remove blocked venues.
