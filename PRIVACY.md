# Privacy Policy

Delivery Hider does not collect, sell, or transmit personal data to external servers in the current release.

The extension stores only the user's blocked venue list, local hide/unhide counts, and optional local-only queued telemetry events in Chrome storage so hidden restaurants and shops remain hidden across supported delivery pages and the local "top blocked" view can work.

If the user explicitly opts into the future telemetry setting, the extension still only queues anonymous event payloads locally in this release. No telemetry is transmitted until a future release adds a backend and updated disclosures.

Delivery Hider does not use remote analytics, remote code, third-party tracking, or external servers for extension functionality.
